# MCL PPT plugin

Makes PowerPoint decks for Mahanadi Coalfields Ltd. Every slide gets:
- the MCL logo in the top right corner
- the footer "Mahanadi Coalfields Ltd"
- a blue, black and white theme

## Install (in Claude Code)
Run these two commands inside Claude Code:

    /plugin marketplace add gujjumanojkumar-collab/mcl-team-5
    /plugin install mcl-ppt@mcl-team-5

Then just ask: "Make a PPT on ...".
